Password Reset
==============

If you've forgotten your HPC password, you can use the form below to initiate a request for a new, temporary password. When you login with this password, you'll then be prompted to set a new one.

.. raw:: html

    <p><form action="https://help.cropdiversity.ac.uk/scripts/passwords/generate-link.sh" method="get">
        <label for="email">Email address:</label>
        <input type="email" size="35" id="email" name="email" required />
        <input type="submit" value="Submit"/>
    </form></p>

.. note::
  Ensure you use the email address associated with your HPC account for this to work.
